# NexShot Technologies - Official Championship Portal 2026

Official multi-page tournament portal for the **2nd Late Smt. Kiran Chopra Shooting Championship 2026**, powered by **NexShot Technologies** at **BBC Shooting Academy, Babu Bodhraj Convent School, Sikandrabad, District Bulandshahr, Uttar Pradesh – 203205**.

## 🌟 Architecture & Features

- **Pioneer Dusky Twilight Design**: Smoked frosted glass cards, coral action accents (`#FF5B37`), 8-point crosshair stars, 60–120 FPS mobile responsiveness.
- **Smart Automated Category Selector**: Strict gender-based match filtering compliant with NRAI Rule 11 (Male sees strictly male categories; Female sees strictly female categories).
- **Official 46 Match Codes (AR-01 to AR-23 & AP-01 to AP-23)**: Auto-resolves shots, fee, age criteria, and target type (SIUS Electronic / Paper Target).
- **Free Custom T-Shirt Live Mockup**: Athletes see their name rendered in real time on the official tournament jersey.
- **Live Leaderboard & Category Scoring**: SIUS Electronic scoring with series breakdown (S1–S6), decimal precision, active firing indicators, and COC qualification cutoffs.
- **Competitor Digital Pass**: 10-digit mobile lookup with QR code and 1-click printable gate pass.
- **Range Master Console & Disaster Recovery**: Offline-first local cache engine with 1-click JSON database export, CSV roster generation, and emergency restore.
